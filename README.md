# VOID

Gerador de senhas desenvolvido em **C# / .NET**, com PostgreSQL e uma API REST para demonstração de conceitos de desenvolvimento backend.

> **Aviso:** Este projeto é exclusivamente **material educacional e de estudo sobre desenvolvimento de APIs**. Não deve ser utilizado como sistema de gerenciamento de senhas em produção.

## Sobre o projeto

O VOID é um projeto experimental criado para estudar e demonstrar conceitos como:

* Desenvolvimento de APIs REST;
* C# e .NET;
* Entity Framework Core;
* PostgreSQL;
* Hashing de dados;
* Persistência de informações;
* Controle de senhas já utilizadas;
* Testes automatizados;
* Concorrência em operações de banco de dados.

## Tecnologias

* C#
* .NET 10
* ASP.NET Core
* Entity Framework Core
* PostgreSQL
* Npgsql
* xUnit

## Segurança

As credenciais de banco de dados utilizadas durante o desenvolvimento são mantidas **localmente** e não fazem parte do repositório público.

Arquivos de configuração contendo informações sensíveis são ignorados pelo Git através do `.gitignore`.

## Objetivo

O principal objetivo do VOID é servir como **material prático de aprendizado sobre APIs e desenvolvimento backend**, permitindo experimentar conceitos de persistência, segurança, testes e integração com banco de dados em um projeto real.
